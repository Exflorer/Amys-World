# Amy's World

**Amy's World** ist ein eigenes Anime-inspiriertes Browsergame-Projekt.

Das Spiel soll keine Kopie eines bestehenden Animes sein, sondern eine eigene Welt, eigene Charaktere und eine eigene Geschichte besitzen. Inspirationen aus düsteren Anime-, Fantasy-, Mystery- und Horrorwelten sind erlaubt, aber das Projekt bleibt eigenständig.

## Genre

- Anime-Adventure
- Story-Spiel
- Mystery
- Horror
- Fantasy
- Action

## Hauptfigur

Die Hauptfigur heißt **Amy**. Um sie herum entwickelt sich die gesamte Geschichte des Spiels.

## Atmosphäre

Amy's World soll düster, geheimnisvoll und teilweise gruselig wirken. Der Spieler soll oft das Gefühl haben, dass etwas nicht stimmt.

Wichtige Stimmungselemente:

- geheimnisvolle Orte
- flackerndes Licht
- Nebel
- seltsame Geräusche
- unerwartete Ereignisse
- versteckte Räume
- Geheimnisse

## Grafikstil

- Anime-Stil
- nicht realistisch
- schöne Lichteffekte
- Nebel
- Magie
- Partikeleffekte

## Musikrichtung

Die Musik soll geheimnisvoll, ruhig, episch und leicht unheimlich wirken. Sie soll selbst erstellt werden und keine bestehende Musik kopieren.

## Spielprinzip

Der Spieler erkundet verschiedene Gebiete und erlebt eine spannende Geschichte.

Geplante Elemente:

- Rätsel lösen
- Gegner bekämpfen
- Hinweise sammeln
- neue Orte freischalten
- Geheimnisse entdecken
- die Geschichte Stück für Stück erleben

## Kampfsystem

Geplant sind animeartige Kämpfe mit:

- Spezialfähigkeiten
- Ausweichbewegungen
- Kombos
- Bosskämpfen

## Startmenü

Das Startmenü soll modern, atmosphärisch und leicht animiert sein.

Geplante Menüpunkte:

- Spiel starten
- Einstellungen
- Spiel verlassen

## Technische Basis

Erste Version als Browsergame:

- HTML
- CSS
- JavaScript
- Canvas für spätere Spiel- und Effektlogik
- modulare Struktur für spätere Minispiele

## Projektziel

Ziel ist ein eigenständiges, hochwertiges Anime-Spiel mit spannender Story, düsterer Atmosphäre, Mystery-Elementen und einer Welt, die Schritt für Schritt erweitert werden kann.
